Configuración de Puerto Virtual (macOS / Linux)
Crea un par de puertos virtuales enlazados con socat:
socat -d -d pty,raw,echo=0 pty,raw,echo=0
Verás algo como /dev/ttys001 y /dev/ttys002.
Conecta el emulador al primero y configura SloTime con el segundo.

Windows: usa com0com para crear un par virtual COM3↔COM4.
